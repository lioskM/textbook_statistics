# 実行指示書 (astra 向け) 第3回: シンプソンのパラドックスの二度説明（A7）

作成: 判定役, 2026-09-06。Ryosuke「シンプソンの件は先に扱いましょう」。作業場所は同じ worktree（`astra/local-fixes`）。絶対条件は第1回 §1 と同じ。**コミットしない。**

## 何が起きているか

読者は第8章「部分と全体で向きが逆になる」で, 学部A・Bの合成データによる相関の逆転を読み, そこで**シンプソンのパラドックス**を太字で導入される（`correlations.tex`「この現象は\textbf{シンプソンのパラドックス}と呼ばれる.」）。第10章の冒頭でバークレー校の合格率を読むと, 同じ名前が**もう一度太字で導入**され（`limitations_and_ethics.tex`「集計の単位を変えただけで結論が逆転する. このような現象を\textbf{シンプソンのパラドックス}と呼ぶ.」）, 「前に読んだ説明の言い直しではないか」と感じる。

第8章と第10章で**残すもの**は違う。第8章は相関の向きが逆転する仕組み（2群の平均の位置と偏差の積）で, 第10章は割合の逆転と「第三の変数」（あとの「相関は因果ではない」の節が, バークレーの話を交絡の実例・層別の手続きとして引く）。バークレーの例と第三の変数の説明は第10章に要る。**要らないのは, 名前の二度目の導入と, 第10章の中で具体（学部間で10倍の差, 狭き門）を言った直後に同じことを抽象で言い直す段落。**

## 触るところ（`chapters/limitations_and_ethics.tex` のみ。第8章は触らない）

### 1. 二度目の導入を, 前に見たことへの接続に替える

位置: `集計の単位を変えただけで結論が逆転する. このような現象を\textbf{シンプソンのパラドックス}と呼ぶ.`（1行）

直し: 太字の導入をやめ, 相関の向きが逆転する例として前に見たシンプソンのパラドックスが, ここでは割合で起きている, という接続にする。章番号は書かない（「前に」「相関を扱ったときに」のような内容の名指し）。1行のまま。

### 2. 具体の直後の抽象の言い直しを縮める

位置: 次の4行の段落。
```
ただし, 集計の単位そのものが結論を狂わせたのではない.
学部によって合格率が大きく違い, 学部選びに男女差があった. この2つが重なって, 「学部」という第三の変数が性別と合格率の両方に絡んでいた.
全体集計はその第三の変数を隠し, 学部別の集計は表に出す. 集計の際に第三の変数が隠れているか表に出ているかが, 結論を左右していた.
群によって混ざり方の違う第三の変数がある場面なら, 同じ逆転は平均の比較でも割合の比較でも起こりうる.
```

何が起きているか: 2行目前半（合格率が違い, 学部選びに男女差）は, 6行上の段落（合格率6\%と64\%, 狭き門と広き門）の言い直し。残すべきは, この事情に「第三の変数」という名前を与えること（あとの節が使う）と, 全体集計がそれを隠すこと。

直し: 4行を**2〜3行**に。「学部」という第三の変数が性別と合格率の両方に絡んでいたこと, 全体集計がそれを隠し学部別の集計が表に出すこと, を言う。「集計の単位そのものが結論を狂わせたのではない」は残してよい（読者の誤解を先回りしている）。4行目（平均の比較でも割合の比較でも）は, 第8章が相関で, ここが割合で見せた以上, 読者はすでに二つの形を見ているので落としてよい。削る行は行そのものを消す。

### 3. 節の末尾の受けを確かめる

位置: `シンプソンのパラドックスは, このうち最後の解釈の段階で起きている. 全体で集計したことが, 第三の変数を隠していた.`

直し: 1・2 の反映後に読み, そのまま通るなら触らない。「第三の変数」の語が 2 で残っていることを確かめる。

## 触らないもの

第8章 `correlations.tex` のシンプソンの節（太字の導入はこちらに残す）。第10章の「相関は因果ではない, ではどう違うのか」の節（バークレーを交絡の実例として引く箇所）。
