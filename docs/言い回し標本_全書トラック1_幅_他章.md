## §1. 判定の線

第5章再パスで確定した三役の線を, この26件にそのまま当てる。①区間そのものは定義語「区間」（第5章 `defi{信頼区間}` の後）に戻し, 信頼区間の定義より前にある第2章では素の言い方（どこからどこまで）にほどく。②区間の広さは「区間の広さ」「区間が広い/狭い」。③ばらつき・散らばりの範囲は「ばらつき」「散らばり」「散らばりの大きさ」で, 定義後は定義語（標準誤差・標準偏差）に戻す。26件のうち18件が③に集中しているのは, 第4章が第5章再パス前の第5章と同じ型で「幅」を $\sigma$・$\mathrm{SE}$ の別名として節を縫っているためで, 第4章12件はこの一本の線で片づく。差し替えに使う名詞・動詞はすべて本文から引いた（散らばりの大きさ = 第2章 `:221`・第4章 `:304`, 散らばりのほう = 第2章 `:173`, どれくらい散らばるか = 第4章 `:312`, どこからどこまでにいそうか = 第5章 `:3` 見出し, 範囲で見積もる = 第5章 章題, 区間を作る = 第5章 `:134` 見出し, 場所によって散らばりが違わないか = 第10章 `:175` 小見出し）。第9章 `:58`・第9章 `:465`・第10章 `:122` の「散らばりの幅が場所によって大きく違わない」は逐語同期しているので, **3箇所とも「散らばりが場所によって大きく違わない」に揃える**。階級の幅（第3章9件・第4章 `:62`）と四分位範囲の幅（第2章 `:154`）は日常語の仕事をしているので残す（§3）。

## §3. 現状維持（11件）

### 階級の幅 — 第3章9件（`:109` `:114`×3 `:116` `:166` `:171`×2 `:174`）・第4章 `:62`

ヒストグラムの階級は, 第3章 `:92--93` で「視聴回数の範囲をいくつかの区間に分け」「区切ってできた一つひとつの区間を\textbf{階級}」と定義されている。その区間の広さを言うのが「階級の幅」で, ここでの「幅」は区切りの大小という日常語の仕事をしている。第5章の①②③のどれでもない——区間そのものでも, 信頼区間の広さでも, ばらつきの範囲でもなく, 読者が図の横軸で目に見えて指させる棒の太さのことである。しかも第3章 `:109--116` の段落は「幅をどう取るかで図の印象が変わる」ことを主題にしていて, 幅そのものが読者に判断させたい対象になっている。語が対象にではなく語どうしに接続する上滑り（v14 §3 日常語の昇格）とは逆で, ここでは語が図の上の一箇所を名指ししている。

「階級の幅」は統計の標準的な言い方でもあり, 定義語（階級）とその属性（幅）という関係が読者に見えているので, 定義のない語が主役の座に着く型にはならない。第3章9件のうち5件は「階級の」を省いた形（`:114` の2件目・3件目, `:171` の2件目, `:174`, `:116`）だが, いずれも1〜2行上に「階級の幅」があり（`:174` は空行を挟んで別段落だが, 2行上の `:171` を受ける）, 省略の先が読者に追える。省略のために語が独り歩きしている箇所はなかった。

第4章 `:62`「その分布の形は, 階級の幅にも, どの80本を引き当てたかにも左右されない」は, 第3章のこの主題（幅を変えると図の印象が変わる）をそのまま受けて, 理論分布はその影響を受けないと言う箇所である。ここで語を替えると, 第3章で読者が見た当のものを指し直せなくなる。残す。

### 四分位範囲の幅 — 第2章 `:154`

現物は「$Q_1$ と $Q_3$ で挟まれた範囲には, ちょうど真ん中の $50\%$ の観測値が入っている. 四分位範囲 $\mathrm{IQR}$ は, その範囲の幅を1つの数にしたものだ.」で, 直前の定義ブロックが $\mathrm{IQR} = Q_3 - Q_1$ を定めている。$\mathrm{IQR}$ は $Q_1$ と $Q_3$ の隔たりそのものなので, 「その範囲の幅」は比喩でも別名でもなく事実の記述にあたる。次の行「真ん中の半分が狭いところに固まっているのか, 広く散らばっているのかを表している」が「狭い/広い」で受けており, 幅・狭い・広いの三語が同じ対象について一貫している。

第5章の②（区間の広さ）に見えるが, 線が違う。第5章で不可だったのは, 定義語「区間」があるのに日常語「幅」がその座を奪っていたことで, ここには奪われる定義語がない——$\mathrm{IQR}$ という定義語は「幅を1つの数にしたもの」の側であって, 幅そのものではない。「その範囲の広さ」に替えることもできるが, 替えても読者の得るものは変わらず, $\mathrm{IQR}$ が差であるという事実からは「幅」のほうが近い。**第2章にこの1件だけを残すことになるが, 同じ章の `:320` `:324` を処理すれば「幅」が章を縫う糸にはならない**（残る1件は定義ブロックの直後の説明文1箇所のみ）。残す。
