# 工事 (d) の反証

## 数理

### 1

- 対象: 束B「ゴセットの分母は, 等分散の仮定を頼りに二つの群のばらつきを一つの推定量にまとめてあり, 一つにまとまっているからこそ, 全体が自由度 $n_1 + n_2 - 2$ のカイ二乗分布の枠にきれいに収まる.」
- 何が食い違うか: カイ二乗分布に従う量と, $t$統計量の分母そのものが区別されていない. カイ二乗分布に従うのは, 正規母集団のもとでプールした不偏分散を母分散と自由度で尺度調整した量であり, 平方根を取った標準誤差そのものではない. 「一つにまとまっている」だけでは, この分布になる理由も示せない. 旧本文にもあった曖昧さが, 一文化した案にも残っている.
- 現物の根拠: `docs/起草_付録_検定の数理_2026-09-16.tex` の対象文. 同ファイルの統計量の式は `t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\dfrac{u_1^2}{n_1} + \dfrac{u_2^2}{n_2}}}` であり, 「各群の分散をそれぞれの標本サイズで割って足し合わせ, 平方根をとったものだ.」と説明している. カイ二乗分布の定義は「平均0, 分散1の正規分布に従う独立な変数を二乗して足し合わせたものが従う分布」である. `chapters/statistical_test_precise.tex` にも「ゴセットの分母は, 等分散の仮定を頼りに, 二つの群のばらつきを一つの推定量にまとめてあった.」「一つにまとまっているからこそ, 全体が自由度 $n_1 + n_2 - 2$ のカイ二乗分布の枠にきれいに収まる.」がある.

### 2

- 対象: 束B「この連立を解いて自由度の側に出てくる値が, 端数のついた $\nu \approx 68.936$ である.」
- 何が食い違うか: 元の和の期待値と分散を一致させる段階と, 未知の母分散を標本の不偏分散で置き換える段階が省略なく同じ計算であるようにつながっている. 不偏分散の和の期待値・分散は未知の母分散に依存するため, モーメントを一致させる連立を解くだけでは, 手元の不偏分散から求めた自由度の数値にはならない. 母分散を推定値で置き換える段階が必要である. これは旧本文から残る説明と式の隔たりである.
- 現物の根拠: `docs/起草_付録_検定の数理_2026-09-16.tex` は「置き換え先の期待値と分散を元の和のそれぞれに一致させる」と述べた直後に対象文を置く. 一方, 自由度の式は `\nu = \frac{\left( \dfrac{u_1^2}{n_1} + \dfrac{u_2^2}{n_2} \right)^2}` を分子とし, 分母も `\dfrac{(u_1^2/n_1)^2}{n_1 - 1} + \dfrac{(u_2^2/n_2)^2}{n_2 - 1}` と, 標本から求める不偏分散で書かれている. 同ファイルは「ところが母分散は未知で, 手元の不偏分散で代用するしかない.」とも述べている. `chapters/statistical_test_precise.tex` でも「この連立を解いて自由度の側に出てくる値が, 前節で計算した」に続けて同じ不偏分散による式を置いている.

### 3

- 対象: 束B「小数第5位まで見てはじめて0.02760, 0.02756, 0.02755と分かれる.」
- 何が食い違うか: 掲載された文字列では, 0.02760の小数第4位は6, 残る二値の小数第4位は5であり, 三値の違いは小数第4位ですでに現れている. 三値すべてを互いに区別できるのが小数第5位であることと, 違いが初めて現れる桁が混同されている. 数値自体の転記違いではなく, 旧本文から残る説明の問題である.
- 現物の根拠: `docs/起草_付録_検定の数理_2026-09-16.tex` の「自由度68でも68.936でも69でも小数第3位までは同じ0.028で, 小数第5位まで見てはじめて0.02760, 0.02756, 0.02755と分かれる.」. `chapters/statistical_test_precise.tex` にも「小数第5位まで見てはじめて0.02760, 0.02756, 0.02755と分かれる程度で, どれを使っても結論は動かない.」がある. ここでは掲載文字列の桁を比較しただけで, 数値は再計算していない.

## 章間整合

### 4

- 対象: 束AのA-2の修正後段落と, 束B「そして, 比である $t$ も, 厳密には$t$分布に従わなくなる.」
- 何が食い違うか: A-2の修正後段落は, 平均の差の$t$統計量が$t$分布に従うと断定したまま, 分母の推定によって$t$分布になる理由を加えている. A-1で本書の検定をWelchと同定すると, この説明はWelchの統計量についての断定となるが, 束Bでは厳密には従わず, 近似として使うと説明している. A-2の断定は第6章現物から残るものである.
- 現物の根拠: `docs/起草_第6章補足_2026-09-16.md` のA-2修正後には「平均の差の$t$統計量なら\textbf{$t$分布}, カテゴリの偏りのカイ二乗統計量ならカイ二乗分布と呼ばれる分布に従う.」と「ここで正規分布ではなく$t$分布が出てくるのは, $t$統計量の分母に手元のデータから計算したばらつきが入っているからだ.」がある. A-1には「こうして組み立てた$t$検定を\textbf{Welchの$t$検定}と呼ぶ.」がある. `docs/起草_付録_検定の数理_2026-09-16.tex` は対象文に加え「厳密には$t$分布でないとしても, 近似的に$t$分布として扱えれば実用上はそれで足りる.」と述べる. `chapters/statistical_test.tex` にもA-2が残す「分布に従う.」の文がある.

## 削除で失われるもの

### 5

- 対象: 束Bの「Welchで何を仮定しているか, そして仮定が崩れたら」の小節の削除と, 束AのA-1・A-2への移設.
- 何が食い違うか: 小標本で$t$分布を使う説明は残る一方, 小標本と強い歪みが重なる場合や, 外れ値が平均を強く動かす場合にはWelchの近似も信頼しにくいという具体的な注意が, 第6章への移設にも付録の短縮にも残っていない. 残る「標本サイズがそれなりにあれば」という説明では, 外れ値による問題を特定できない. 順位検定・ブートストラップの名称が消えること自体ではなく, $t$分布を使っても解消されない場合の目安が失われる点を指摘する.
- 現物の根拠: `chapters/statistical_test_precise.tex` には「一方で, 標本サイズが小さく, かつ元の母集団が大きく歪んでいる場合や, 外れ値が平均を強く動かしている場合には, この近似が効かなくなり, Welchの結果も信頼しにくくなる.」がある. `chapters/probability_distribution.tex` の指定範囲には「$n$ が小さいときの扱いには, $t$分布という分布を使う方法が知られている.」がある. `docs/起草_付録_検定の数理_2026-09-16.tex` には「逆に標本が小さいときほど, 正規分布で済ませると, 裾の重さを無視して「実際より珍しい」と判定してしまう.」が残る. 同ファイルの前提の補足は「標本サイズがそれなりに大きければ, 中心極限定理によって各群の標本平均は正規分布に近づき, その差もまた正規分布に近づく.」までである. `docs/起草_第6章補足_2026-09-16.md` のA-1にも「標本サイズがそれなりにあれば中心極限定理から二つの平均の差を正規分布として扱えること」はあるが, 削除元の歪み・外れ値の注意はない.
