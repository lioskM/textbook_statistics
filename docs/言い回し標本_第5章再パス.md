## A群 : 章の骨格（6件）

### A-1. 章の動機が, 発明した報告の場面でできている

**現物 `:5--15`（5.1 の冒頭。章全体の入口）**

```
前章で, 平均を取り直したときのばらつきの幅が, 標準誤差 $\mathrm{SE} = u/\sqrt{n}$ という一行の計算で見積もれるようになった.
報告や記録には, 平均とあわせてこの標準誤差も書く, というところまでが前章の話だった.

ただ, 報告を受け取る側の立場で考えると, まだ物足りない.
「平均はおよそ4.2, 標準誤差はおよそ0.1です」と言われても, その平均をどこまで信用してよいのかは, すぐには読み取れない.
標準誤差の定義を知っている相手ならともかく, 多くの読み手にとって標準誤差は馴染みのない数字だ.
せっかく計算したばらつきの目安が, そのままでは相手に届かない.

届く形は, おそらく幅だ.
「本当の平均は, だいたい4.0から4.4の間で見ています」と言われれば, 統計を知らない相手でも意味が取れる.
標準誤差という一つの数字を, こうした幅のかたちに直せないだろうか.
```

**診断:** v12 §3「変な立場を持ち込まない」の直撃。11行のうちに「報告を受け取る側の立場」「と言われても」「相手」「多くの読み手」「相手に届かない」「と言われれば」「統計を知らない相手」が並ぶ。**これが章の動機になっている**ことが重い。

しかも単発ではなく, 章をまたいで組まれている。

- 第4章 `:427--430`（前章の締め）: `ただ, 実際の報告の場面を考えると, もう一歩足りない. 「平均はおよそ何回, 標準誤差はおよそ何回」と伝えられた相手は, その平均をどこまで信用してよいのか, まだ読み取りにくい.`
- 第5章 `:5--15`（本章の導入）: 上記。**前章の締めをほぼ逐語で言い直している。**
- 第5章 `:394`（章末の回収）: `前章の終わりに, 標準誤差を誰が読んでも同じ意味になる幅に直したい, という宿題を立てた.`
- 第5章 `:402`（章末の着地）: `この読み方さえ共有されていれば, 幅を添えた報告は, 見積もりの精度ごと相手に渡る.`

`:402` は**リズム原則 ペア10 の Before そのもの**である。ペア10 は「幅を添えた報告は, 見積もりの値だけでなく, その見積もりの精度まで相手に渡す」を棄却し, 「幅があれば, 見積もりの値だけでなくその精度までわかるから〜」に直した。その確定版は `:128` に入っている。**同じ文が章末にもう一つあり, そちらは直っていない。**

**本当の動機は何か。** 標準誤差は「取り直したときにどれくらい動くか」を言うが, 「母平均がどこからどこまでにいそうか」は言っていない。これは読者が自分の推定を受け取るときの不足であって, 誰かに伝える場面は要らない。そして本文はすでに正しい言い方を持っている——`:40` **「では, $\bar{x}$ だけを頼りに, $\mu$ の居場所をどこまで絞り込めるだろうか.」**

**判定役の判断:** 報告の場面を章の動機から外し, `:40` が言っている不足で入る。ただしこれは A-6（5.1 と 5.2 冒頭の反復）と一体で決まるので, **文の起草は A-6 の裁定とあわせて行う。**

### A-3. 「幅」の一語三役

v12 §3 は第5章の「幅」を**二役**（区間そのもの／区間の広さ）と記録したが, 現物は**三役**である。

| 役 | 意味 | 件数の目安 | 例 |
|---|---|---|---|
| ① | 95\%信頼区間そのもの | 約31 | `:24 幅を添えて` `:69 幅のかたちで言えるようになった` `:235 幅つきで言える` `:402 幅を添えた報告` |
| ② | 区間の広さ（上端と下端の隔たり） | 約20 | `:148 そのぶん幅は広がる` `:267 割合の幅は $\pm 11$ ポイント` `:296 $n$ を4倍にすれば幅は半分` |
| ③ | 標本平均の散らばりの範囲 | 6 | `:5 ばらつきの幅` `:45 そのばらつきの幅は標準誤差で測れる` `:46 ばらつきの幅がわかっているなら` `:64 $\mathrm{SE}$ は $\bar{x}$ 自身のばらつきの幅` |

**診断:** ③は定義ブロックより**前**に置かれ, ①②は定義の**後**に来る。読者は同じ語で, 標本平均の散らばり → 区間 → 区間の広さ の三つを順に受け取る。とくに `:64` が悪い——`$\mathrm{SE}$ は $\bar{x}$ 自身のばらつきの幅だから, この区間は…` で, **一文の中に③（ばらつきの幅）と①（この区間）が同居している。** 同じ対象を二つの語で呼んでいるのか, 違う対象なのかが読み取れない。

本文がすでに持っている言い換え:

- ①の代わり → **区間**（定義語。`:60` `:63` `:64` `:104` `:110` ほか多数）
- ②の代わり → **広い／狭い**（`:174` `区間はすっぽり規格内に入っており` `:176` `区間が規格からはみ出しており` `:203` `かなり広い`）, **区間の端／下端／両端**（`:206` `:287` `:376`）
- ③の代わり → **ばらつき**（`:44` `$\bar{x}$ はばらつく`）, **どれくらい離れうるか**（`:50`）, **動きうる**（`:64` `$\bar{x}$ が動きうるぶんだけ`）
- 定義前の①の代わり → **だいたい4.0から4.4の間**（`:14` に現物がある）

**判定役の判断:** 三役すべてを解く。定義後は定義語（区間）, 定義前は素の言い方（だいたいどこからどこまで）, ③は「ばらつき」「動きうる範囲」に戻す。62件のうち, ②の一部（`:302--304` の `幅は $\pm 0.80$` など数値表示）は残す余地があるので, B群で一件ずつ判定する。

### A-4. `:402` は, 確定済みの棄却案がそのまま残っている

**現物 `:399--402`（章末）**

```
そして, 幅の読み方も決まった.
95\%は区間そのものの性質ではなく, 区間を作る手順の当たりやすさだ.
手元の一本が当たりか外れかは分からないが, 繰り返せば95\%当たる作り方で作った一本として報告し, 受け取る.
この読み方さえ共有されていれば, 幅を添えた報告は, 見積もりの精度ごと相手に渡る.
```

**診断:** リズム原則 ペア10 が棄却した Before（`幅を添えた報告は, 見積もりの値だけでなく, その見積もりの精度まで相手に渡す.`）と, 語順まで含めてほぼ同じ文である。ペア10 の確定版は `:128` に入っており, **同じ章の中に, 直した版と直っていない版が両方ある。**

### A-6. 5.1 が 5.2 の内容を先に言ってしまい, 節単位の反復になっている

**現物**

5.1 `:17--21`:
```
直すこと自体は, じつは簡単で, 標準誤差をおよそ2倍して平均の左右に広げるだけでよい.
問題はそのあとに待っている.
作った幅の「だいたい」とは, どのくらいの確かさなのか.
「この幅の中に本当の平均がある」と言い切ってよいのか.
ここがいちばん間違えやすいところであり, まずは, 出てきた幅をどう理解するかを固めておく必要がある.
```

5.2 `:35--53`（同じ道筋を最初からたどり直す）:
```
いちばん素直なのは, 「母平均はおよそ4.2だろう」と, 手元の値をそのまま見積もりに使うことだ.
（点推定の定義）
ただ, 前章で見たとおり, $\bar{x}$ は標本を取り直すたびに異なる値をとる.
つまり, $\bar{x}$ をそのまま $\mu$ だと言い切ってしまうのは, 少し心もとない.

では, $\bar{x}$ だけを頼りに, $\mu$ の居場所をどこまで絞り込めるだろうか.
（…中心極限定理 → $\pm 1.96 \times \mathrm{SE}$ → 定義ブロック）
```

さらに 5.1 `:23--24`:
```
そのうえで, 幅の作り方を平均以外にも広げる.
章の終わりには, 平均・割合・2群の差のどれにでも同じ作り方で幅を添えて, その幅の意味を一文で言えるはずだ.
```

**診断:** 三つ重なっている。

1. **答えの先出し。** `:17` が結論（2倍して左右に広げる）を出したあと, 5.2 が `:35--53` で同じ結論をゼロから導出する。v12 §1「実践より先に答えを計算してしまう」（第9章 標本9）と同型。
2. **予告。** `:23--24` は 5.3・5.4 の見出しがそのまま言っている内容の予告。要件定義書§4.4 メタ宣言, リズム原則 ペア15 の型。「その幅の意味を一文で言えるはずだ」は**読者の到達状態の断定**でもある（v12 §3「確かめていないことを書かない」）。
3. **`:18`「問題はそのあとに待っている.」** は v12 §1「語りの足場で中身を運ぶ」の問題提起の型（ペア13「問題は〜点にある」）。

**判定役の判断:** 5.1 は A-1 の報告の場面と, この予告・答えの先出しを両方抱えている。**節ごと組み直す必要がある。** 残すべきは「標準誤差はばらつきを言うが, 母平均がどこにいそうかは言っていない」という不足だけで, それは 5.2 の `:40` がすでに正しく言っている。

**したがって選択は二つに絞られる。**

- **(a) 5.1 を大幅に縮め, 動機の一段だけを残して 5.2 へ渡す**（報告の場面・答えの先出し・予告をすべて落とす。5.1 は4〜6行になる）
- **(b) 5.1 を節ごと廃し, 5.2 の冒頭に統合する**（`:40` を章の入口に上げる）

判定役は **(a)** を採る。本書の全章が「問い」節から始まる構成を採っており, 第5章だけ落とすと章の並びが崩れる。ただし現状の5.1（22行）は動機として長すぎ, 中身は「標準誤差だけでは母平均の居場所が言えない」の一点なので, 大幅に縮む。
