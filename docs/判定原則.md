# 判定原則

判定役 (Claude Code) がセッション累積で確立した, 要件定義書に未収載の判断原則。
役割分担の絶対則は `CLAUDE.md` の「役割規律」を参照。

## 判定の根拠

- **表面形の流通確認**: 日本語表現の妥当性は, 類似慣用の存在確認で判定を止めず, 当該表面形が対象文体で実際に流通しているかまで確認する。逆に, 直感だけで欠陥と断定しない。禁止パターンへの機械的合致か, 検索による確認を根拠とする。
- **口語それ自体は欠陥ではない**。口語と不自然の線引きを網羅的に規則化しない。
- **機械走査は補助, 通読が主** (言い回しパス実測 9:23)。
- **効率化は目的にしない**。反復・手直し・ゼロからの書き直しは正常な工程。
- 内容の正しさは全判断基準の最上位。統計的主張の真偽は判定役が数理的に確定する。

## 指示書の書き方 (Codex 向け)

- **文体を扱うときは規範を条文で書かない**。リズム原則v4 の該当 Before/After ペア番号と適用箇所だけを渡す。条文化した指示書は書き直し。
- **数値の実計算をさせない旨を明記**する。数値が必要な箇所はプレースホルダ可。
- 位置指定は本文文字列で行う (行番号不可)。

## 用語・言語

- 統計用語は統計web (bellcurve.jp) の表記に準拠。
- 教科書本文に関わる思考は日本語で行う。
