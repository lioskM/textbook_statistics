## 5. 密度の計算に使った Python

`.venv/Scripts/python`（scipy 1.17.1）で実行した。

```python
from scipy.stats import t as tdist

df = 68.936                                  # Welch の t 検定の自由度 (巻末付録の実践例)
xs = [round(-4 + 0.05 * i, 2) for i in range(161)]   # -4.00 から 4.00 まで 0.05 刻み
pts = [(x, tdist.pdf(x, df)) for x in xs]

print(" ".join("(%.2f,%.5f)" % (x, y) for x, y in pts))            # 曲線
print(" ".join("(%.2f,%.5f)" % (x, y) for x, y in pts if x <= -2.30))  # 左の塗り
print(" ".join("(%.2f,%.5f)" % (x, y) for x, y in pts if x >= 2.30))   # 右の塗り
```
検算 : 自由度 68.936 の $t$ 分布で $P(|T| \geq 2.3) \approx 0.0245$、$P(|T| \geq 2.251) \approx 0.0276$（巻末付録の 0.0276 と一致）。図には数値を書かない方針なので、この値は本文にも図にも出さない。
