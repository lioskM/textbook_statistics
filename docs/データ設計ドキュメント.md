# ランニング例 データ設計ドキュメント

ランニング例設定メモ(改訂版)に基づく架空データの数値設計方針. 本書全章で一貫して使用する.

---

## 0. 設計の基本方針

1. **教育的扱いやすさを優先する**: 各章で示したい統計現象が確実に出るよう, 分布形・相関の強さを設計する.
2. **実データらしさを失わない**: 過度に整った値や不自然に強い相関は避ける. 散布図に現実的なばらつきを残す.
3. **章間の整合性を保つ**: 同じデータ生成プロセスから, 全章の演習が成立すること.
4. **可能な範囲で再現可能性を確保する**: 乱数シードを固定し, 教科書記載の値が再現できるようにする.

---

## 1. データ規模

- 標本サイズ: **N = 80** (確定)

確定根拠:
- 4章のCLT演習(20作品ずつ無作為抽出 × 複数回)に十分な母集団的役割を果たせる
- 5章の区間推定で, 標準誤差が大きすぎず小さすぎない値域を取れる
- 6章の検定で, 原作あり群・原作なし群がそれぞれ十分なサンプル数を確保できる(実データは37本/43本)

確定の経緯: データ生成・全章の執筆・数値検証まで N=80 で完了しており, 本文と図の全数値がこの規模に依存する(確定数値の一覧は docs/修正方針.md §4 第2群). 以後変更しない.

---

## 2. 各変数の値域・分布形

### 公開後30日間視聴回数 (主変数)

- 値域目安: 数千 〜 数百万回
- 分布形: 右に歪んだ分布(対数正規分布を想定)
- 設計のポイント:
  - 平均と中央値が明らかに異なる(2章の代表値の議論材料)
  - ただし超ヒット作1本が全体を支配するほどには歪ませない. 上位の値が他より極端に離れすぎない設計とする
  - 4章のCLT演習で, n=20程度の標本平均を取ると正規分布に近づく様子が視覚的に確認できる程度の歪み

### 製作費

- 値域目安: 数千万円 〜 10億円程度
- 分布形: 右に歪んだ分布
- 設計のポイント:
  - 邦画実写の中堅以下作品レンジ
  - 視聴回数との相関は **弱〜中程度** (r ≈ 0.3〜0.5)
  - 「製作費を上げれば視聴回数が伸びる」という素朴な期待への部分解にとどまる程度

### 平均評価 (5段階)

- 値域: 1.0 〜 5.0
- 分布形: J字型または高めの値に偏った分布
- 設計のポイント:
  - 実際のレビュー分布の特徴(高評価寄り)を再現
  - 視聴回数との相関は **弱め** (r ≈ 0.1〜0.3)
  - 「高評価だから多く見られる」という素朴な期待を部分的に外す

### 評価件数

- 値域目安: 5件 〜 数千件
- 分布形: 強く右に歪んだ分布
- 設計のポイント:
  - 視聴回数とは強く相関する(見られた回数に比例する傾向)
  - 件数の少ない作品で平均評価のばらつきが大きくなる構造(3章の散布図材料)

### おすすめ表示回数

- 値域目安: 視聴回数の数倍程度
- 分布形: 右に歪んだ分布
- 設計のポイント:
  - 視聴回数との相関は **中〜強程度** (r ≈ 0.6〜0.8)
  - ただし因果の向きはデータからは決められない(8章の議論材料)

### 上映時間

- 値域: 90分 〜 150分程度
- 分布形: ほぼ対称(やや右寄り)
- 設計のポイント:
  - 他変数との強い相関は持たせない
  - 4章の補助変数としても使える(対称な量的変数の例)

### ジャンル

- カテゴリ例: サスペンス, コメディ, 恋愛, ヒューマンドラマ, アクション など
- 設計のポイント:
  - 4〜6カテゴリ程度
  - 各カテゴリのサンプル数に偏りを持たせる(現実的)
  - ジャンル別の視聴回数分布に多少の差を持たせる(3章の箱ひげ図材料)

### 原作の有無

- カテゴリ: オリジナル脚本 / 既存作品の映画化
- 設計のポイント:
  - 概ね半々に近い比率
  - 原作あり群の方が平均視聴回数がやや高い(6章の検定で有意差が出る程度)
  - ただし分布の重なりは大きい(差はあるが個々の作品では逆転も多い)

## 3. 変数間の相関構造(設計目安)

| 変数1 | 変数2 | 相関の強さ目安 | 設計意図 |
|---|---|---|---|
| 製作費 | 視聴回数 | 弱〜中 (r ≈ 0.3〜0.5) | 8章で「直感より弱い」を体感. 9章単回帰の説明変数. |
| おすすめ表示回数 | 視聴回数 | 中〜強 (r ≈ 0.6〜0.8) | 8章で因果の向きの議論材料 |
| 平均評価 | 視聴回数 | 弱 (r ≈ 0.1〜0.3) | 「高評価=多く見られる」の期待を外す |
| 評価件数 | 視聴回数 | 中〜強 (r ≈ 0.6〜0.8) | 見られた回数に概ね比例 |
| 上映時間 | 他変数 | ほぼ無相関 | 独立な変数として確保 |

数値は設計時の目標. 実装・検証済みで, 本文が使う実測値は次のとおり確定した(data/running_example.csv): 製作費×視聴回数 r = 0.3650, おすすめ表示回数×視聴回数 r = 0.8033, 平均評価×視聴回数 r = 0.2057. いずれも設計目安の範囲内である(おすすめ表示回数は上端).

## 4. 各章執筆時の留意点

ランニング例設定メモには書かないが, 執筆時に意識すべき点を記録する.

### 2章 データの要約

- 視聴回数の歪みは「平均と中央値が違うとわかる程度」で抑える
- 超大ヒット作が全体を完全に支配するほどには歪ませない(後続章での回帰・検定が壊れる)

### 4章 確率分布とCLT

- 「全作品リストから20作品を無作為に選んで」のような表現は全知視点気味になる
- 「もし同じような調査を何度も行い, 20作品ずつ選んだら, 標本平均はどのように散らばるだろうか」のような表現に調整する
- データ提供元から繰り返し標本を取れる設定として書く

### 5章 推定

- 母集団の定義を明示する: 「ここでの母集団は, このサービスで同じ年に公開された邦画実写作品全体である」
- そのうえで「この母集団自体も世界全体の映画を代表しているわけではない」を10章で回収する二段構え

### 6章 検定

- 「原作あり vs 原作なし」は交絡が残る(原作あり作品は知名度・製作費・宣伝規模が大きい可能性)
- 検定では「平均視聴回数の差が出た」事実までで止める
- 「原作の有無が視聴回数を増やしたと証明したわけではない」と注意する

### 8章 相関

- おすすめ表示回数と視聴回数の関係について, 因果の向きが決められないことを明示する(メモにも記載済み)
- 相関係数だけでは「表示されたから見られた」とも「見られたからさらに表示された」とも読めることを書く

### 9章 回帰

- 単回帰の便利さと物足りなさを同時に示す章とする
- 製作費から視聴回数を予測する → 外れる → 外れた作品を見るとおすすめ表示回数や評価件数が関係していそうに見える, という流れ
- 多変量回帰には踏み込まないが, 「不足感」を読者に持たせる

### 10章 統計の限界とバイアス

- 視聴回数は作品の質ではない
- 平均評価は評価した人だけの平均である
- おすすめ表示回数が露出バイアスを生む
- 年内累計視聴回数は公開月で歪む
- 邦画・実写・特定の年というサンプリングの限界
- 標本抽出の仮定の妥当性を改めて検討する

## 5. 実装方針

- 言語: Python (pandas, numpy, scipy)
- 出力形式: CSV (data/running_example.csv)
- 乱数シード固定 (seed=42)
- 生成は data_generation/generate_running_example.py, 検証は data_generation/verify_running_example.py

実装済み. 本文・図が参照する確定数値の一覧は docs/修正方針.md §4(第2群)にある. 数値を変える場合は同§4の再計算パスに従い, スクリプトで一元管理する(章ごとに手入力しない).

## 6. 図の生成規約

textbook.mplstyle が担っているスタイル知見の文書化(2026-08-09 監査で追記).

- スタイルは figures/scripts/textbook.mplstyle に一元化する. 全章のスクリプトが `plt.style.use` で読み込み, 個々のスクリプトでスタイル設定を上書きしない.
- 配色は Okabe-Ito パレット(色覚バリアフリー). 群や範囲の区別は色だけに頼らず, 点の形・線種・濃淡を併用して白黒印刷でも読み分けられるようにする(例: 第4章の±σ範囲は線種と濃淡, 第8章のシンプソンの図は点の形と線種).
- 図は章別スクリプト figures/scripts/chNN.py で生成し, データは ch03_data.load_movies() 経由で data/running_example.csv から読む. 数値の手打ちをしない.
- 出力は figures/output/ に PDF と PNG の両方. git 管理は PDF のみ.
- 本文の主張を目で確かめる役割の図だけを作る. 装飾目的の図は作らない(修正方針§4 第3群).
