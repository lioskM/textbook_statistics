## A-1 実践の結果の前に、使った検定の名前と前提を置く

場所: 「原作の有無で平均視聴回数に差はあるか」の節。「検定統計量は, 二つのグループの平均とばらつきから$t$統計量として計算する.」から始まる段落。

### 1. 修正前の段落（現物）

```
    検定統計量は, 二つのグループの平均とばらつきから$t$統計量として計算する.
    $p$値は, 「平均視聴回数に差がない」と仮定したときに, 得られた$t$統計量と同じかそれ以上に極端な値が出る確率として, $t$分布から求める.
    あらかじめ有意水準を$\alpha = 0.05$と決めておき, 実際に計算してみる.
    $t$統計量はおよそ2.25, そこから求めた$p$値はおよそ0.028だった.
    0.05を下回ったので帰無仮説は棄却され, 「原作の有無で平均視聴回数に差がある」という主張が支持される.
    どちらが高いかは標本平均を見ればよく, 原作あり群の274.1万回に対して原作なし群は153.7万回である.
```

### 2. 修正後の段落

```
    検定統計量は, 二つのグループの平均とばらつきから$t$統計量として計算する.
    このとき, 二つのグループのばらつきが同じだとは仮定しない.
    母集団のことが直接わからないからこそ検定をしているのに, その母集団についてばらつきだけは等しいと決めてかかるのでは, 話が噛み合わない.

    それでも, 各グループの中では視聴回数が同じ分布から得られていること, そして標本サイズがそれなりにあれば中心極限定理から二つの平均の差を正規分布として扱えることは, 前提として残っている.

    あらかじめ有意水準を$\alpha = 0.05$と決めておき, 実際に計算してみる.
    $t$統計量はおよそ2.25, そこから求めた$p$値はおよそ0.028だった.
    0.05を下回ったので帰無仮説は棄却され, 「原作の有無で平均視聴回数に差がある」という主張が支持される.
    どちらが高いかは標本平均を見ればよく, 原作あり群の274.1万回に対して原作なし群は153.7万回である.
```

## A-2 $t$ 分布を使う理由を置く

場所: 「珍しさを数値にする：$p$値」の小節。候補 (i) を採る。「その散らばり方は理論的にわかっていて, 平均の差の$t$統計量なら\textbf{$t$分布}, カテゴリの偏りのカイ二乗統計量ならカイ二乗分布と呼ばれる分布に従う.」の直後。

### 1. 修正前の段落（現物）

```
    頼りになるのは, 帰無仮説のもとで検定統計量がどんな値をとりやすいか, という分布である.
    差が本当になくても, 偶然のばらつきのせいで$t$はゼロちょうどにはならず, ゼロの周りに散らばる.
    その散らばり方は理論的にわかっていて, 平均の差の$t$統計量なら\textbf{$t$分布}, カテゴリの偏りのカイ二乗統計量ならカイ二乗分布と呼ばれる分布に従う.
    この分布の中で, いまの値と同じかそれ以上に極端な値が出る確率を求める.
    それが\textbf{$p$値}である.
    $p$値が小さいほど, 帰無仮説のもとでは起こりにくい結果が出ている, と理解できる.
```

### 2. 修正後の段落

```
    頼りになるのは, 帰無仮説のもとで検定統計量がどんな値をとりやすいか, という分布である.
    差が本当になくても, 偶然のばらつきのせいで$t$はゼロちょうどにはならず, ゼロの周りに散らばる.
    その散らばり方は理論的にわかっていて, 平均の差の$t$統計量なら\textbf{$t$分布}, カテゴリの偏りのカイ二乗統計量ならカイ二乗分布と呼ばれる分布に従う.
    ここで正規分布ではなく$t$分布が出てくるのは, $t$統計量の分母に手元のデータから計算したばらつきが入っているからだ.
    分母が偶然小さく出た標本では同じ差でも$t$の値が膨らみ, そのぶん$t$分布は正規分布より裾が重くなる.
    標本が大きくなれば分母が偶然小さく出ることも減り, $t$分布は正規分布に近づいていく.
    検定統計量が従う分布の中で, いまの値と同じかそれ以上に極端な値が出る確率を求める.
    それが\textbf{$p$値}である.
    $p$値が小さいほど, 帰無仮説のもとでは起こりにくい結果が出ている, と理解できる.
```

### 3. 変えた行だけの一覧

| 旧文 | 新文 |
|---|---|
| （新規追加） | `ここで正規分布ではなく$t$分布が出てくるのは, $t$統計量の分母に手元のデータから計算したばらつきが入っているからだ.` |
| （新規追加） | `分母が偶然小さく出た標本では同じ差でも$t$の値が膨らみ, そのぶん$t$分布は正規分布より裾が重くなる.` |
| （新規追加） | `標本が大きくなれば分母が偶然小さく出ることも減り, $t$分布は正規分布に近づいていく.` |
| `この分布の中で, いまの値と同じかそれ以上に極端な値が出る確率を求める.` | `検定統計量が従う分布の中で, いまの値と同じかそれ以上に極端な値が出る確率を求める.` |

最後の1件は、3行を挟んだことで「この分布」の直前が $t$ 分布になり、カイ二乗分布が落ちて読めるのを防ぐための置き換えである。「検定統計量が従う分布」は同じ段落の「〜分布に従う」から引いた。「帰無仮説のもとでの分布」（「検定の手順」のステップ4 の言い方）も当ててみたが、段落内に「帰無仮説のもとで」が三度並ぶので採らなかった。

### 4. 決めた理由

(i) を選んだ。$t$ 分布の名前が初めて出るのはこの文で、読者が「前章までは正規分布だったのに」と止まるのもこの瞬間だから、答えは同じ場所に置く。実践の段落には A-1 で四文足すので、そこへ分布の由来まで重ねると、五つのステップに沿って結果に着くまでが遠くなる。

前章を名指しで引き合いには出さなかった。前章の区間も分母には標本から計算した標準誤差を使っており、「前章までは正規分布で済んでいたのに」と対比させると、前章の計算が間違いだったように読める。「正規分布ではなく」の一語で読者の引っかかりは受けられるし、三文目の「標本が大きくなれば正規分布に近づく」が、前章の概算が通っていた理由まで兼ねる。
