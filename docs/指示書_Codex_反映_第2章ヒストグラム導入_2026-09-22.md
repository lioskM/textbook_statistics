- 図は変えない。`figures/scripts/ch02.py` は星の図を隙間つきの棒 (`ax.bar`, width 0.8), 80 本の図を隙間なし (`ax.hist`, 等幅 12 区間) で描いており, 差し替え後の本文と一致している。

### #3 80 本の図でヒストグラムを出す (2 行 → 7 行)

直前の二行「この80本のデータについても, 図を描いて全体の姿を確かめてみよう.」「星の評価と違って, 視聴回数は値の種類が多すぎて, 値ごとに数えると棒が一本ずつバラバラに立ってしまう.」は変えない。その直後の次の 2 行を

```

    \cref{fig:ch02-views}がその図である.
```

次の 7 行に置き換える (脚注の継続行も半角スペース 4 つのインデント。年収の脚注と同じ書式)。

```
    そこで, 視聴回数を等しい幅の区間に分け, それぞれの区間に何本の映画が入るかを数えてみる.
    この区間を\textbf{階級}といい, 区間に入った本数が度数になる.
    \cref{fig:ch02-views}では, 横軸に階級を取り, 区間ごとの本数を棒の高さで表している.
    このように, 数値を区間に分けて度数の分布を表す図を\textbf{ヒストグラム}と呼ぶ\footnote{%
    ヒストグラムは, 棒の面積が度数に比例するように描く.
    ここでは階級の幅をそろえているので, 度数をそのまま棒の高さにできる.
    幅が異なる場合は, 度数を階級の幅で割って高さを決める.}.
```

置き換え後も, その次の行は `    % 図のデータ: 仮. 要作成` のままで, 空行の数も変えない。
