## 2. 採集の方式（第1〜7章と同じ）

1. **通読で引っかかった文をすべて拾う。理論による選別をしない。** ×だろうと思っても網に載せる（×予測の的中は第5章 0/5・第6章 1/5・第7章 3/3。的中し始めたが運用は変えない——v9 §4）。
2. 各標本の構成: 本文からの**逐語引用**（位置指定は本文文字列。行番号は目安扱い）／引っかかりの説明（v9 の根・過去標本との同型は出典つきで。条文にない違和感もそのまま出す）／確信度（高・中・低・×予測）／案（高確信は必ず、中以下もできる限り）。
3. **機械走査**: `uv run python tools/style_check.py --files chapters/correlations.tex` を実行し、出力の全件を確認する。基準値（2026-08-16 時点）: **block 8件**（やり方1・ch-ref 7）・**flag 8件**（ぶつん切れ疑い5・問い3）。**走査に出たものは全件、標本の場に出す**。自分の判断で容認して落とさない（v9 §4）。
4. **機械走査に載らない確定禁則の手走査**も行う（第7章で実施した項目）: 素の t・r 等の記法（地の文の統計量記号が数式モードか）／地の文の素の「SE」「SD」（`se-jibun` 規則は `$\mathrm{SE}$` しか拾わない。第7章 標本23の教訓）／遠称・対比の指示語（あちら・こちら）／述語を省いた体言・数式・数値止め／節番号参照（`sec-ref` で機械化済みだが確認）／「標本分散」等の用語の揺れ（第7章 標本19の教訓: 章内で定義した語と別の名前が来ていないか）。
5. **数理に触れる文は、理由づけを数学的に確かめてから標本に立てる**。数値の再現計算もできる範囲で行う（第7章では scipy で全数値を検算し、数値は全部正しく理由づけだけが誤っている型を4件拾った）。
6. 標本の途中で規則が確定的に見えたら、**その場で章全体に走査を掛け直す**（v9 §4）。
7. 成果物: `docs/言い回し標本_第8章.md`。第7章の文書と同じ構成（冒頭に方式、標本、走査で出たもの、判定欄、全書トラック登録、Codexレビュー記録、申し送り）。

## 4. 起草の手順（v9 §4 の縛りをそのまま適用）

- 網に掛かった語だけを見ない。**その文の残りと段落の構造まで読んでから**標本に立てる。
- 言い直しに見える二文は、語ではなく**情報**で比べる。
- 案を差し替えるたびに、**その文と前後のつながりまで全文を通して読み直す**。数式ブロックへ接続する文は、式との接続が切れないか確かめる（第7章 標本21の器合わせ）。
- 冗長・ヘッジ・重複を外す前に、それが何を防いでいるかを言葉にする。
- **数理の理由づけは、書く前に式と計算に突き合わせる**（v9 §4）。成り立たない理由を作らない。
- **確定した直しを別の章へ横展開するときは、参照関係を確かめ直す**（v9 §4。「第5章」→「前章」は第6章でだけ正しかった）。
- 起草した案は提出前に自己点検する: 抽象語一語の締め／ぶつん切れ／述語を省いた引用句・体言・数値止め／自問の語尾／遠称指示語／名詞化／「問い」「と読める」／解釈動作の一般化／作った場面や立場／語りの足場。

## 5. Codexレビュー（第7章で試験→本採用）

**位置**: 標本文書の草稿（標本＋案）が揃った後、Ryosuke に出す**前**。

**方法**: Codex プラグイン（codex:rescue）でレビュータスクとして投げる（編集なし・読み取りのみ・--fresh）。読ませるファイル: 標本文書・リズム原則 v9・**第8章本文・隣接章の本文**（第7章 `statistical_test_precise.tex`・第9章 `regression.tex`。第7章の試験で最も効いた指摘は章間整合と数理の現物照合だった）。

**Codex への指示テンプレート**（第7章と同文＋追加1項）:

> あなたは統計学教科書（文系大学生・社会人向け）の文体修正案のレビュー担当です。以下の修正案（旧文→新文）を、教科書の読者として読んでください。
>
> してほしいこと: 新文に残っている欠陥、または新文が新たに持ち込んだ欠陥を指摘する。とくに (1) 数理の理由づけが数学的に正しいか、(2) 案が前後の章の本文と食い違っていないか、(3) 削除案で失われる情報がないか。
>
> 各指摘には根拠を必ず一つ添える: (a) 本文・修正案の該当文字列とその問題の説明、(b) 辞書的事実（語の意味・用法の誤り）、(c) 添付のリズム原則の該当項目。
>
> してはいけないこと: 代わりの文章を書くこと（書き直し案の提示は禁止。欠陥の指摘まで）。リズム原則を上から順に照合するチェックリスト式のレビュー。根拠のない語感だけの指摘。標本文書の診断に同意するだけの応答。
>
> 出力: 指摘ごとに「対象（標本番号と該当文字列）／欠陥／根拠」。指摘がなければ「なし」と書く。

**採否**: 各指摘の採否は採集セッション（判定役代行）が決め、採った指摘だけ起草に反映する。反証を素通しで Ryosuke に出さない。棄却の理由も記録する。

**記録**: 第7章と同じ較正表（指摘／根拠種別／採否と理由／Ryosuke判定後の的中）を標本文書末尾に残す。第7章の集計は 13指摘/11採用/2棄却・採用の7件が判定役案の欠陥・的中欄は全件妥当、だった。この水準を下回るかを見る。
