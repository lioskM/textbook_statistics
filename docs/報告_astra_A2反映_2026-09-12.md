## 項目6

旧（逐語）:
```
    視聴回数のように歪んだデータでは, 正規分布はデータの形の記述としては出番がなかった.
    しかし, そのデータから計算した平均が取り直しでどうばらつくかを考えると, そこには正規分布が現れる.
    それも元の形を問わずに現れるのだから, データが釣鐘型かどうかを心配する必要すらない.
```

新（逐語）:
```
    視聴回数のヒストグラムは, 釣鐘型にはほど遠かった.
    それでも, 標本を取り直しては平均を計算することを繰り返せば, その平均の散らばりは正規分布に近づいていく.
    元のデータがどんな分布でもそうなるのだから, 手元のデータが釣鐘型でなくても, 正規分布を使ってよい. ただし使えるのはデータそのものにではなく, 平均の分布に対してである.
```

実施・未実施: 実施。
