- 数値の計算は発生しない。

## 作業手順

### 作業1: 第4章

`chapters/probability_distribution.tex` で, 次の置換を行う。

```
置換後:
```
    $n$ が小さいときの扱いには, t分布という別の道具が知られている（第6章で登場し, 中身は第7章で確かめる）.
