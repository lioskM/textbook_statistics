## 2. 付録の設計

### 2.1 読者と役割

付録を読むのは, 第6章で「$t$ 統計量はおよそ2.25, $p$ 値はおよそ0.028」「自由度3のカイ二乗分布」と出てきた数字がどこから来たのかを確かめたい読者である。第6章を読み終えている。第8章以降はこの付録に依存しない。付録の役目は, その読者の疑問 (数字の出どころ, なぜその分布か, 自由度とは何か, Welch の自由度がなぜ整数でないか) に答えること。第6章で済んだこと (検定の枠組み, 仮説の立て方, 片側・両側, 二つの過誤, 効果量, Welch の名称と前提) は繰り返さない。

### 2.2 節の順序

現行の四節を, 次の順に並べ替える。カイ二乗分布の定義が Welch の節で使われる前に来るようにするため。

1. 自由度 (現行の第1節)
2. $t$ 検定の計算 (現行の第2節。「なぜ正規分布ではなく $t$ 分布なのか」を含む)
3. カイ二乗検定の計算 (現行の第4節。「なぜカイ二乗分布と比べられるのか」の定義がここで出る)
4. Welch の $t$ 検定の自由度 (現行の第3節)
5. 締めの段落 (現行 592〜596 行目)。残すか削るかを決める。

### 2.3 削る・縮める

目安は 596 行を 350 行前後にすること。ただし行数は目標ではない。残す基準は, 上の読者が持っている疑問に答えている行かどうか。

- **自由度の節**: 母集団と標本の再説明 (「検定で本当に比べたいのは」から「構造としては「平均からのずれの二乗の平均」と覚えておけば十分だ.」まで) は第4章・第5章で済んでいるので縮める。二乗の展開から $n-1$ に至る計算, 「データが1個しかないとき」の例, 「標本平均を固定して残りの自由さを見る」は残す (ここがこの節の答え)。「自由度は分散の推定だけの話ではない」は, 次の節へ渡す一二文に縮める。
- **$t$ 検定の計算の節**: 数値の代入は残す。Welch の同定 (「この式は, $u_1$ と $u_2$ を最後まで別々に扱っている.」から「その分母としてこの式が現れている.」まで) は, 第6章で名前と前提が出るので, 分母の形がそれにあたることを言う一二文に縮める。「ずいぶん込み入った式である.」からの三文は, Welch の節が後ろに移るので「あとの節で」に合わせて直す。信頼区間との対応 (「差の95\%信頼区間がゼロを含むかどうか」から「この二つの判定は必ず一致する.」まで) は残す。「なぜ正規分布ではなく $t$ 分布なのか」は残す (第6章には二三文しか入らない)。
- **カイ二乗検定の計算の節**: 八つのマスの計算, 自由度 $(2-1)\times(4-1)$ の勘定, 「なぜカイ二乗分布と比べられるのか」を残す。第6章を指す参照を直す。
- **Welch の自由度の節**: 最も縮める (157行を 60〜80 行に)。残すのは, 端数がつく疑問の提示, ゴセットが等分散を仮定して整数自由度を得たこと, その仮定を外すと分母が一つのカイ二乗分布にまとまらないこと, 期待値と分散を合わせてカイ二乗分布に寄せる発想, 出てきた式を眺める段落 ($w_1 = w_2$ で標本サイズだけで決まる, $n_1 = n_2$ で $n_1 + n_2 - 2$ に一致), 「自由度という言葉が二つの意味を持っている」の着地。削るのは, 「$t$ 分布族はもともと実数で定義されている」の小節 (ガンマ関数の話。$\nu$ が正の実数なら分布として意味を持つこと, 端数を丸めても $p$ 値が小数第3位まで変わらないことの二点を, 一二文で別の小節に吸収する), 「Welchで何を仮定しているか, そして仮定が崩れたら」の小節 (実践に要る前提は第6章へ移る。付録に残すのは, 厳密な導出は各群が正規分布に従うときに成り立ち, 標本が大きければ中心極限定理で近似が効く, という区別の二三文まで。順位検定・ブートストラップへの言及は残すか削るかを決める)。
- 同じ構造を次の節で念のためもう一度置く形 (第7章に11組あった) は, 一度だけにする。
- 脚注は増やさない。既存の脚注は残すか削るかを内容で決める。

## 3. 書き方の線 (リズム原則の要点。読んだうえで守る)

- 報告する人・受け取る相手・聞き手のような場面を作らない。
- 「問い」の抽象用法, 「読み方」「見方」「〜方」, 「〜と読める」「〜と読もうとして」を使わない。「もう一つの見方」の小見出しは見直す。

- 削除案は, 削る文と残る文の両方を読んでから出す。残る文が削る文に「も」「その」で寄りかかっていないかを見る。
- 書いたら, 付録全体を読者として通して音読し, 「繰り返し破られた線」を上から当てる。当たった項目があれば語を替えるのではなく人格から書き直す。
