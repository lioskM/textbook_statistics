## 4. 第6章 `chapters/statistical_test.tex`

### 項目 A. 入口の段落(3行→4行)

旧:
```
    信頼区間からわかるのは, 差がどこからどこまでにいそうかだけだ.
    目の前の差は, 偶然のばらつきとして片づけられる範囲に収まっているのか, それを超えているのか.
    この一歩踏み込んだ問いに白黒をつける手続きが, 前章の終わりに名前だけ挙がった\textbf{統計的検定}だ.
```
新:
```
    信頼区間からは, 差がどこからどこまでにいそうかが分かった.
    同じ情報を使えば, 「差がない世界だとしたら, 今回ほどの差はどれくらい珍しいのか」を考えることもできる.
    その珍しさを, あらかじめ決めた基準と比べて, 偶然で説明できるかどうかを判断するのが, 前章の終わりに名前だけ挙がった\textbf{統計的検定}だ.
    基準を先に決めておくので, 誰がやっても同じ判断になる.
```

### 項目 B. 「判断の基準を先に決める」の小節(1行→1行)

旧:
```
    $p$値だけで白黒をつけることには限界があり,
```
新:
```
    $p$値だけで判断することには限界があり,
```
