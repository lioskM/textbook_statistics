# 構造見直し方針: 第6章・第7章

作成: 判定役 (Claude Code), 2026-08-09
起点: Gemini 通しレビューで裏づけられた通し読みの弱点 3件 (受け入れ条件 R1〜R3)

## 1. 見直しの範囲についての診断

通しレビューの読者体験報告では, 第1〜6章と第8〜10章の流れ・積み上げ・ペースは機能しており, 読書体験の断絶は第6章→第7章→第8章の継ぎ目に集中していた。現物照合でもこれを支持する事実のみが確認された。

**診断: 構造問題は全10章の並びではなく, 第6章と第7章の内容分担に局在する。** 章の本数・順序は動かさない。

## 2. 症状と構造的原因

### 症状

読者は第7章冒頭の案内「ここを読まなくても, 第8章から先を読み進めるのに支障はない」(`statistical_test_precise.tex` 冒頭) に従ってスキップする。その結果:

- 第6章が立てた問い「原作の有無で平均視聴回数に差はあるか」の答え ($p \approx 0.0276$, 棄却) を読めない
- 血液型×性格のカイ二乗検定の結論も読めない
- 効果量 (Cohen の $d$) の導入を読まないまま, 第10章「7章で触れた効果量」に突き当たる

### 構造的原因

第7章に性質の異なる三種類の内容が同居し, スキップ案内が三つをまとめて対象にしていることが原因である。

| 種別 | 内容 (第7章内の該当節) | スキップしてよいか |
|---|---|---|
| (a) 数学的背景 | 自由度の意味 / t統計量の形の由来 / Welch の自由度公式 / カイ二乗分布との対応 | よい (深掘り) |
| (b) ランニング例の結論 | 映画データの $t=2.251$, $p=0.0276$, 棄却 / 血液型データの計算結果 | **いけない** (第6章の物語の回収) |
| (c) 検定を使う上の必須概念 | 検定の二つの誤りと限界 (詳説) / 効果量 | **いけない** (第10章の前提) |

スキップ案内自体は誤りではない。(a) だけなら案内どおりで支障はない。(b)(c) が (a) と同じ章に住んでいることが欠陥である。

## 3. 方針

**内容を「検定を使うために必要か / 検定の中身を理解するために必要か」で再仕分けする。**

- **第6章 = 検定を使う章として完結させる**。考え方 + 実践の結論 (b) + 使う上での必須概念 (c) をすべて収める。読者はこの章までで検定を使えるし, ランニング例の答えも受け取る。
- **第7章 = 検定の中身の数理 (a) だけの章にする**。スキップ案内は残す。再仕分け後は案内が完全に正直になる: 読まなくても本当に何も欠けない。

各章の性格が一行で言えるようになる (第6章「検定を使う」, 第7章「検定の中身」)。これが検討した案の中で最も短い手術で, 最も明快な形である。

### 具体的な移動・修正

1. **映画データの結論を第6章へ**: 第6章「原作の有無で平均視聴回数に差はあるか」節の末尾で, 結果の数値 ($t \approx 2.25$, $p \approx 0.028$) と結論 (棄却, ただし原因の特定は別問題) を言い切る。計算の過程は第7章に残し, 「この数値がどう出てくるかは第7章で」と案内する。「具体的な計算は第7章で手を動かしながら確認する」(現 `statistical_test.tex` の当該文) は削除または書き換え。
2. **血液型データの結論を第6章へ**: 同様に, カイ二乗検定の結果と結論を第6章の血液型節で言い切る。あわせてカイ二乗検定に向きの区別がない理由の一文を追加 (R2)。
3. **「検定の二つの誤りと限界」節を第7章から第6章へ移設**: この節はほぼ数式を含まず, 第6章の「数式を最小限に」の方針と両立する。第6章に既にある第1種・第2種の過誤の簡易導入 (有意水準の説明中のボックス) と統合する。
4. **「効果量と実質的な差の検討」節を第7章から第6章へ移設**: Cohen の $d$ の式は分数一つで, 第6章の水準に収まる。第6章末尾の「差の大きさそのものは, 効果量という別の指標で測る. 第7章と第10章で改めて扱う」は, 効果量を章内で導入する形に書き換え。
5. **参照の張り替え**:
   - 第10章「7章で触れた効果量」→「6章で触れた効果量」
   - 第6章末尾の次章予告を新分担に合わせて書き換え (「次章は検定の中身の数理. 読まなくても使える」)
   - 第7章冒頭のスキップ案内は維持 (再仕分け後は正確な案内になる)
6. **第4章の予告文の修正 (R3)**: 「なぜ推論では $n-1$ で割るのかは, 検定の数学的背景を扱う章で確かめる」を, 直感的な理由は第5章のコラムで・数理は第7章で, と読者の到達順に合わせて書き換え。

### 移動しないもの

- t統計量・カイ二乗統計量の計算過程 (第7章に残す。結論は第6章, 過程は第7章)
- 信頼区間と検定の対応の数値確認 (対応関係の言明は第6章に既にあり, 数値での確認は深掘りとして第7章が適所)
- 自由度・Welch・分布の由来の全節 (純数理, 第7章の本体)

## 5. 検討して退けた案

- **第7章の付録化** (Gemini 案): 章番号の振り直しと全章の参照修正が発生する。得られるのは「章か付録か」というラベルの違いだけで, 本質は内容の再仕分けにある。仕分けだけなら改番は不要。
- **第7章の解体・各章への分散**: 数理の深掘りが各章に散らばり, 数式を避けたい読者が章ごとに数式の塊に出会う。「深掘りは一箇所に隔離」という現行設計のほうが読者体験は明快。
- **第6章と第7章の統合**: 一章が肥大化し, 「数理はスキップ可能」という設計自体が失われる。
