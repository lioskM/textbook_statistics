## A1. 数理編の短縮と付録化

### 現物の確認

数理編の入口は, 進路に数理編を置いたまま通過しなくてもよいと告げる。

```tex
    本章では, 前章で組み立てた検定の, 数学的な背景に立ち入る.
    $t$統計量やカイ二乗統計量がなぜその形なのか, 自由度とはそもそも何なのかを, 式の内側まで確かめていく.
    そのぶん数式は多くなる.
    ただし, ここを読まなくても, 次章から先を読み進めるのに支障はない.
    先へ進んでおいて, あとから戻ってきても構わない.
```
定義順の問題は次の二文と, 章末に置かれた定義との関係にある。

```tex
    $t$分布なら, 標本平均と不偏分散を組み合わせて作るので, 分散の自由度 $n-1$ が分布の形を決める.
    カイ二乗分布なら, 正規変数の二乗和として作られ, 合計を固定するといった条件の数だけ自由度が減る.
```

```tex
    カイ二乗分布は, 理論的には, 平均0, 分散1の正規分布に従う独立な変数を二乗して足し合わせたものが従う分布として定義され, 足し合わせる個数が自由度になる.
```

数値から確率への操作の欠落は後掲の式17・27にある。原作別の近似判断が結果より前にないことも現物で確認した。

### 設計案

短縮した数理編を巻末付録へ移す。本文は検定の概念・実践・結論から相関へ直接進む。付録は次の三節と二つの注にする。

1. **自由度と分散推定**。標本平均を固定した偏差の制約を図で示す。既存の単一観測の例で, 分散ゼロと推定不能を区別する。その後, 不偏分散と期待値の結果を結ぶ。制約の個数を数える説明と不偏性の証明は同一視しない。
2. **カイ二乗分布と度数のずれ**。正規変数の二乗和による分布の定義を最初に置く。既存の血液型の仮設例で, 観測表→独立という仮説→期待度数→規模を揃えたずれの二乗→周辺合計の制約→帰無仮説のもとでの近似分布→右裾の確率, の順。分布の定義とクロス集計への近似適用を区別する。
3. **分散推定を含む標準化と Welch 法**。分母も標本から推定するため変動することを先に扱う。独立な正規変数とカイ二乗変数から作る比による t 分布の定義を担わせ, 正規母集団での厳密な由来と Welch 法の近似を区別する。正の実数自由度も分布の形を指定すること→等分散を仮定しない理由→近似自由度の意味→原作別データでの t の計算→ソフトで自由度・両裾確率の取得, の順にする。小数自由度を使ってから理由へ戻る順をやめる。
4. **注: 不偏分散の勘定**。二乗和分解と期待値の差し引きを一度だけ示す。不偏性・一致性の定義の再講義はしない。
5. **注: Welch の近似と計算の内訳**。分散推定量の和を近似すること, 尺度と自由度を期待値・分散の一致で定めること, 未知量を標本推定値で置くことを分ける。自由度公式は一度だけ置く。t の分母と自由度の途中計算, 同じ分布による区間と検定の対応を集約する。

カイ二乗を先にするのは Welch の説明で必要な分布を先に用意するため。付録では本文の検定の出現順の再演より定義の依存を優先する。付録だけで入力を確かめられるよう, データの入力値と最小限の仮説は残す。

残す核は次の制約の説明と単一観測の例。新しい数値の組は作らず図示する。

```tex
    この $n-1$ という数は, 元のデータそのものに最初から制約があるという話ではない.
    元のデータは $n$個とも自由に観測される.
    しかし, そこから $\bar{X}$ という代表値を計算して固定したうえで, 残ったずれ $(X_i - \bar{X})$ を眺めると, ずれの組が自由に動ける余地は $n-1$個分しかない.
    「自由度」という名前は, この見方から来ている.
```

```tex
    極端な場合で確かめておこう.
```

無相関検定・傾きの信頼区間を追加する案は, 新たな標本分布と計算を必要とし, 今回の構造の補修を超える。章末で「扱わない」とだけ断る案は, 既習のばらつきを r・b に適用できないままにする。三条件を全て削除する案は, 将来予測や母集団への主張の根拠まで失う。

### 数理の確認点

判定役が確定する事項: r の算出には両変数の分散がゼロでないこと, 切片つき単回帰の係数の一意性には x の変動が必要であること, 通常の R² には応答の変動に関わる定義条件があること。当てはめの計算と独立性・等分散性を区別する一方で, 「どんなデータからでも」という無条件の主張にしない。母集団の係数の対象, 条件付き平均のモデルと誤差の条件, 不偏性・一致性を保証する条件は別途必要であり, 等分散性の崩れだけから傾きが正しいとは言わない。系列・集団内の連動で不確かさが変わる方向も条件依存。残差223万回は, 傾きの SE や特定の製作費での予測区間として扱わない。今回その区間や検定を計算しない。
