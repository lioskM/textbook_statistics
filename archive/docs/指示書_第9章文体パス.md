## 2. 採集の方式（第1〜8章と同じ）

1. **通読で引っかかった文をすべて拾う。理論による選別をしない。** ×だろうと思っても網に載せる（×予測の的中は第5章 0/5・第6章 1/5・第7章 3/3・第8章 8/8。第7章から的中側に並んでいるが運用は変えない——v10 §4）。
2. 各標本の構成: 本文からの**逐語引用**（位置指定は本文文字列。行番号は目安扱い）／引っかかりの説明（v10 の根・過去標本との同型は出典つきで。条文にない違和感もそのまま出す）／確信度（高・中・低・×予測）／案（高確信は必ず、中以下もできる限り）。
3. **機械走査**: `uv run python tools/style_check.py --files chapters/regression.tex -v` を実行し、出力の全件を確認する。基準値（2026-08-24 時点）: **block 8件**（`ch-ref` 6・**`toyomeru` 2**）・**flag 17件**（`toi` 7・`butsun` 8・`retsukyo` 2）。**走査に出たものは全件、標本の場に出す**。自分の判断で容認して落とさない（v10 §4）。
4. **機械走査に載らない確定禁則の手走査**も行う: 素の $r$・$R$ 等の記法（地の文の統計量記号が数式モードか）／地の文の素の「SE」「SD」／遠称・対比の指示語（あちら・こちら）／述語を省いた体言・数式・数値止め／節番号参照（`sec-ref` で機械化済みだが確認）／**用語の揺れ**（第8章 標本1の教訓: 揺れを見つけたら**どちらが定義されているか**を先に確かめる。多数派に揃えない）。
5. **数理に触れる文は、理由づけを数学的に確かめてから標本に立てる**。数値の再現計算もできる範囲で行う（第8章では `numpy` で相関・外れ値・シンプソンを再現し、数値は全部正しく理由づけだけが誤っている型を2件拾った。第9章は最小二乗法・$R^2$・残差の章なので、係数と $R^2$ の再現は必須）。
6. 標本の途中で規則が確定的に見えたら、**その場で章全体に走査を掛け直す**（v10 §4。第8章 標本47はこれで6箇所が出た）。
7. 成果物: `docs/言い回し標本_第9章.md`。第8章の文書と同じ構成（冒頭に方式、標本、走査で出たもの、判定欄、全書トラック登録、Codexレビュー記録、申し送り）。

## 4. 起草の手順（v10 §4 の縛りをそのまま適用）

- 網に掛かった語だけを見ない。**その文の残りと段落の構造まで読んでから**標本に立てる。**第8章ではこの失敗が一つのパスで四度出た**（文末・述部・主語のねじれ・圧縮の引き継ぎ）。**語の置き換えで済ませられそうな標本ほど、指摘とは無関係な目で文全体を読み直す。**
- **削除案は、削る文と残る文の両方を読んでから出す**（第8章 標本11）。削ったあとに段落を閉じることになる文が、単独で読者に通じるかを確かめる。
- 言い直しに見える二文は、語ではなく**情報**で比べる。
- 案を差し替えるたびに、**その文と前後のつながりまで全文を通して読み直す**。数式ブロックへ接続する文は、式との接続が切れないか確かめる。
- 冗長・ヘッジ・重複を外す前に、それが何を防いでいるかを言葉にする。
- **数理の理由づけは、書く前に式と計算に突き合わせる**（v10 §4）。成り立たない理由を作らない。第8章では反証役に3件止められた。
- **「本書の既定」と書く前に、その根拠（定義・裁定・原則のどれか）を確かめる**。他章で使われているだけの語を既定と呼ばない（第8章 標本1・標本2・標本23の訂正）。
- 起草した案は提出前に自己点検する: 抽象語一語の締め／ぶつん切れ／述語を省いた引用句・体言・数値止め／自問の語尾／遠称指示語／名詞化／「問い」「と読める」／解釈動作の一般化／作った場面や立場／語りの足場／圧縮。

## 5. Codexレビュー（第7章で試験 → 第8章から本採用）

**位置**: 標本文書の草稿（標本＋案）が揃った後、Ryosuke に出す**前**。

**方法**: Codex プラグイン（codex:rescue）でレビュータスクとして投げる（編集なし・読み取りのみ・`--fresh`）。読ませるファイル: 標本文書・リズム原則 v10・**第9章本文・隣接章の本文**（第8章 `correlations.tex`・第10章 `limitations_and_ethics.tex`）。第7・8章とも、最も効いた指摘は章間整合と数理の現物照合だった。

**Codex への指示テンプレート**（第7・8章と同文）:

> あなたは統計学教科書（文系大学生・社会人向け）の文体修正案のレビュー担当です。以下の修正案（旧文→新文）を、教科書の読者として読んでください。
>
> してほしいこと: 新文に残っている欠陥、または新文が新たに持ち込んだ欠陥を指摘する。とくに (1) 数理の理由づけが数学的に正しいか、(2) 案が前後の章の本文と食い違っていないか、(3) 削除案で失われる情報がないか。
>
> 各指摘には根拠を必ず一つ添える: (a) 本文・修正案の該当文字列とその問題の説明、(b) 辞書的事実（語の意味・用法の誤り）、(c) 添付のリズム原則の該当項目。
>
> してはいけないこと: 代わりの文章を書くこと（書き直し案の提示は禁止。欠陥の指摘まで）。リズム原則を上から順に照合するチェックリスト式のレビュー。根拠のない語感だけの指摘。標本文書の診断に同意するだけの応答。
>
> 出力: 指摘ごとに「対象（標本番号と該当文字列）／欠陥／根拠」。指摘がなければ「なし」と書く。

**採否**: 各指摘の採否は採集セッション（判定役代行）が決め、採った指摘だけ起草に反映する。反証を素通しで Ryosuke に出さない。棄却の理由も記録する。

**反証役の後にもう一度自己点検する**（第8章の教訓）。Codex は標本文書と本文の両方を読むが、案の周辺2行の受け渡しまでは拾わない。第8章では反証役を通した後の自己点検でさらに6件の直しが要った。

**記録**: 第7・8章と同じ較正表（指摘／根拠種別／採否と理由／Ryosuke判定後の的中）を標本文書末尾に残す。集計は第7章 13指摘/11採用/2棄却、第8章 8指摘/6採用/2棄却。**採用のうち判定役の案が新たに持ち込んだ欠陥は 7/11・4/6 と、二章続けて6割超**。この水準を下回るかを見る。

## 6. 裁定の運用（第8章で確定）

- **10件ずつの束で提示する。** 第8章は45件を3束（10・10・25）で出したところ、Ryosuke「いやーあなたの指摘ポイントは…」の前に「10個ずつくらいにしないとみられないですよね」となった。**一度に出すのは10件まで。**
- 各件は「旧文 → 新文」を並べ、理由は一行に絞る。詳細は標本文書側に置く。
- 差し戻しだけ挙げてもらう形にする（「よっぽどだめでない限りOK」の運用は第7章から継続）。
- **判断が要る点は、その束の中で明示する。** 束をまたいで持ち越さない。

## 7. 「暫定OK」の扱い（第8章でRyosukeが提起）

> なんか納得できないけど暫定的にOK, みたいなのが増えていってそれが後々の判断に影響していくの嫌ですね。

この懸念は第8章 標本1で現実化していた（定義のない語が既定の顔になり、判定役がそれに合わせようとした）。手当てとして次を守る。

1. 裁定の記録に**暫定の印**を残す。○の中に、積極的に良いと判断したものと、違和感が残るまま通したものがある。
2. 暫定印のついたものは、**リズム原則への還元対象にしない**。
3. 暫定印のついたものを、**「本書の既定」として扱わない**。第8章の暫定は標本22（`correlations.tex` から削除済み。「散布図で見えていた右上がりの印象に、数字がついた。」の型）。**この型に似た表現を第9章で見つけても、第8章で通ったからという理由で容認しない。**
4. 定義なしで既定化した語を見つけたら、全書トラック13へ送る。
