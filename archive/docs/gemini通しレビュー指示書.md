# 通しレビュー指示書 (Gemini 向け)

添付の `main.pdf` (統計学教科書, 全10章) を第1章から最終章まで通しで読み, 以下の観点でレビューしてください。

## あなたの役割

あなたは編集者ではなく, まず**一人の読者**としてこの本を読んでください。読者像は次のとおりです。

- 文系の大学生, または数学的バックグラウンドを仮定しない社会人
- 数学の知識は日本の文系高校生程度 (微積分や線形代数は使えない)
- 確率パート (前巻) は読了済み。期待値・確率変数・確率分布などの基本概念と記法は既知として読む
- 統計学を学ぶのは初めて。義務ではなく, 面白ければ読み進め, 退屈なら本を閉じる

この読者になりきって読み, そのうえで編集者の視点に切り替えて報告してください。

## レビュー観点 (この2つだけ)

1. **面白く読み切れるか**: 途中で本を閉じたくなる箇所はないか。退屈する箇所, 読み飛ばしたくなる箇所, テンポが落ちる箇所はどこか。逆に, 引き込まれた箇所はどこか。
2. **理解できるか**: 読者の理解が止まる箇所はないか。説明の飛躍, 前提知識のギャップ, 「なぜそうするのか」が腑に落ちないまま進む箇所, 疑問が生まれたのに放置される箇所はどこか。

次の点は**レビュー対象外**です。報告しないでください。

- 誤字脱字・表記ゆれ・LaTeX 組版の細部
- 執筆ルールや形式への適合性 (構成が型どおりかどうか等)
- 統計的内容の学術的な網羅性 (「〜も載せるべき」という追加提案)

## 通し読みだからこそ見える点

章単位のレビューは済んでいます。今回は通しでしか見えない次の点を特に注視してください。

- **章間の接続**: 章をまたいだとき, 前章までの流れを受けて自然に読み始められるか。話が突然変わったと感じる箇所はないか
- **概念の積み上げ**: 後の章で使われる概念が, その時点までにきちんと導入・定着しているか。「これ何だったっけ」となる箇所はないか
- **重複と温度差**: 同じ説明の不要な繰り返し, 章によるトーン・難易度の急変はないか
- **全体のペース配分**: 一冊として読んだとき, 息切れする章・駆け足に感じる章はどこか

## 報告フォーマット

Markdown で, 以下の構成で書いてください。

### 1. 総評 (冒頭に)

- この読者は最後まで読み切れるか。あなたの判定を一つ, 理由とともに述べる
- 一冊を通した読書体験の要約 (どこで乗れて, どこで失速したか)

### 2. 指摘一覧 (章ごと)

各指摘は次の形式で。**深刻なものから順に**並べ, 些末な指摘で件数を稼がないでください。

- **位置**: 章・節番号 + 該当箇所の本文引用 (冒頭20〜40字程度)。ページ番号は補助として併記可
- **種別**: 「面白さ」「理解」「流れ (章間・通し)」のいずれか
- **読者の体験**: その箇所で読者に何が起きるか (例: 「ここで初めて出た記号の意味が説明されず, 数式を追うのを諦める」)
- **深刻度**: 高 (読み進める意欲や理解が途切れる) / 中 (引っかかるが回復できる) / 低 (気になる程度)

### 3. 良かった点

読者として特に楽しめた箇所・見事だと感じた説明を3〜5点。理由も添えて。

## 注意事項

- **書き直し文案は不要です**。問題の指摘と, 改善の方向性の一言まで。文案の起草と採否はこちらで行います
- 指摘には必ず「読者に何が起きるか」を書いてください。一般論 (「もっと丁寧に」等) だけの指摘は不採用とします
- 判断に迷う箇所は, 迷った理由ごと報告して構いません
