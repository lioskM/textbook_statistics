## 0. 実態

### 節見出し（`\subsection`）

第2〜4章は, 要件定義書 §5.2 の6ステップの**設計上の呼称がそのまま節見出し**になっている。§5.2 は「本文に表示する節見出しは, 読者にとって直接的な表現に言い換えてよい」と定め, 第6・8・10章は内容の言葉だけ, 第5・9章は「設計語 : 内容」の形で言い換え済み。

| 章 | 設計語のままの節 | 様式 |
|---|---|---|
| 第2章 | 問い／理論の最小核／手法／実践／結果と次の一手（5本。2.2「平均だけでは見えないもの」は内容語） | 設計語のみ |
| 第3章 | 問い／素朴な方法と限界／理論の最小核／手法／実践／結果と次の一手（6本） | 設計語のみ |
| 第4章 | 同上（6本） | 設計語のみ |
| 第5章 | 問い : 母平均は…／手法 : 3つのケースで…／実践 : 80本の映画／結果と次の一手（4本） | 設計語 : 内容（章末のみ設計語のみ） |
| 第9章 | 問い : 製作費が…／素朴な方法と限界 : 目で引いた線は…／実践 : 製作費と視聴回数で問いに答える（3本） | 設計語 : 内容 |
| 第6・8・10章 | なし | 内容のみ |

**読者が目次で最初に見る第2〜4章が「2.1 問い」「2.4 手法」「2.5 実践」で, 何の話か分からない**（第10章 標本文書 B の副産物）。

第4・5・7・9・10章は「 : 」（半角コロン, 前後スペース）, 第6章は「 -- 」, 第8章は「：」（全角コロン, スペースなし）, 第1〜3章は区切りなし。

### 「〜方」の名詞化（読み方・作り方・使い方）

裁定の場で Ryosuke「そもそも読み方というのが忌避すべき書き方として記憶されているはず」（§7）。v14 §3「裸の『読み方』『作り方』のような〜方の名詞化を, 読者がまだその動作を見ていない段階で操作しない」。第5章の章題「信頼区間の読み方と使い方」は本トラックへの申し送りだったが, 判定役は見落とし, 5.2「作り方と95\%の読み方」も既存として素通りした。

走査（コメント行を除く）: **見出し3件**（第5章 `:1` 章題, `:9` 5.2, `:60` 小見出し「95\%の正しい読み方」）。地の文は「読み方」12件（第1章1・第4章1・第5章5・第7章2・第10章3）, 「作り方」9件（第5章）, 「使い方」4件（第4章2・第5章章題1・第9章1）, 「やり方」0件。第10章 `:40`「標本の集め方に入る」は第10章パスで Ryosuke が確定した小見出し, 第7章 `:138`「もう一つの見方」は角度の意味で, どちらも対象外。

**「作り方」9件は動かさない。** 第5章再パスで「文一つ分の中身を連体修飾で手順・作り方に掛けない。名詞は『その作り方』と裸の指示で受けるのが正用」と Ryosuke が確定しており（再パス標本文書 `:519`）, 9件はすべてその裸の指示（この作り方だと・同じ作り方なら・その作り方から）。

**「読み方」「使い方」は, 読者がその動作を見る前に置かれたものだけ直す。** 見出し3件と, 第1章 `:60`「結果の読み方も分かりやすくなる」（読者はまだ何も見ていない）, 第4章 `:403`「この数字の読み方を確認しておこう」（これから示す, の予告）。動作を見た後の裸の指示（第5章 `:97`「この読み方さえ」`:101`「読み方が定まったところで」, 第7章 `:295`「二つの読み方なのだ」, 第10章 `:217` `:221` `:230`「〜という読み方だ」, 第4章 `:67` `:246`・第9章 `:59` の「使い方」）は §3 の線では可の側だが, **Ryosuke の言葉は「読み方」そのものを忌避と読めるので, 残す判断は裁定を仰ぐ**。

コメント行を除き全書30件。見出し7件（2.1・3.1・4.1・5.1・9.1・9.5・9.6）を除く地の文は23件。第6章の6件は第6章パスで判定済み（具体的な疑問を指す4件は残す, 抽象的な3件は処理済み）。残る18件のうち, **具体的な疑問文を指す11件は可**（第1章 `:56` `:58`, 第2章 `:119` `:167`, 第4章 `:9` `:162` `:318` `:416`, 第5章 `:391`, 第7章 `:472`, 第9章 見出し `:452`）。**抽象的な用法が7件**: 第1章 `:67`, 第2章 `:328` `:355`, 第5章 `:294` `:298`（2件）`:361`。いずれも「答えている問い」「同じ問い」の形で, 統計量が問いに答えるという擬人化と講義語が重なっている（[[feedback-toi-yomeru]]）。

## 1. 判定の方針

1. **節見出しは内容の言葉だけにする**（第6・8・10章の様式）。「問い :」「実践 :」の設計語は読者に意味を持たず, 「問い」は講義語。第5・9章の「設計語 : 内容」も枕を落として揃える。要件定義書 §5.2「章ごとに統一する義務もない」は言い換えの自由を認めた文で, 揃えることを禁じてはいない。
2. **見出しの言葉は本文から引く**（v14 §4）。各節の本文がすでに持っている言い方を見出しに立てる。
3. 区切り記号は「 : 」に統一。ステップ見出しは小見出しなら「Step N : 動詞句」（句点なし, 第9章様式）, 段落内の太字なら「Step N : 動詞句.」（句点あり）。
4. 地の文の抽象的な「問い」7件は, 対象を指す言い方（測っているもの・見積もる対象・何が分かるか）にほどく。
