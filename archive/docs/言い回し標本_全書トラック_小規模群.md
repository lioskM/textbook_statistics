
## 3. トラック9 : 「狙う」（全書6件 → 標本1件・×予測5件）

走査語 `狙`。統計量を主語に立てた動作動詞（v12 §3 擬人化）に当たるかを一件ずつ見た。

### 3-1. ○ 第7章 `statistical_test_precise.tex:120`（脚注）

```
$n$ で割る分散は手元のデータの散らばりをそのまま要約する量, 不偏分散は母分散を狙う推定量で, 役割が違う.
```

**診断:** 「不偏分散は……狙う」で, 統計量が主語に立って動作動詞を取っている。擬人化にあたる。しかも「狙う推定量」は, 直後の「推定量」がすでに「母数の見積もりに使う統計量」（第5章 `:418` の定義）なので, 動詞と名詞で同じことを二度言っている。

**案:**

```
$n$ で割る分散は手元のデータの散らばりをそのまま要約する量, 不偏分散は母分散の推定量で, 役割が違う.
```

差し替え語の出どころ（v12 §4）: 「推定量」は第5章 `:418` の定義語（`母数の見積もりに使う統計量を\textbf{推定量}と呼び`）。第7章は第5章より後なので読者は持っている。新語なし。

## 5. トラック12 : 「推論用標準偏差」（全書15箇所）— **裁定を仰ぐ**

### 現物

| 章 | 位置 | 語形 |
|---|---|---|
| 第4章 | `:295` `:340` `:397` | 推論用標準偏差 |
| 第4章 | `:305` | データそのものの散らばりの大きさを**推論用に計算した**値 |
| 第4章 | `:405` | SDである $u$ は, …どれだけ散らばっているかを**推論用に見積もった**値 |
| 第5章 | `:67` `:166` `:213` `:239` `:273`（2回） `:372` | 推論用標準偏差 |
| 第6章 | `:42` | **推論用分散** |
| 第7章 | `:181` `:182` | 推論用標準偏差 |

第4章 `:284` の定義が与えているのは **「$u^2$ は不偏分散, $u$ はその平方根である」までで, $u$ に名前は与えていない。**

いっぽう第8章 `correlations.tex:234` は同じ $\sqrt{\frac{1}{n-1}\sum(x_i-\bar{x})^2}$ を **「標本標準偏差」** と呼んでいる。

### 診断

v12 §4 が第8章 標本1 で確定させたところ:
> 判定役は多数派を本書の既定と見なして第8章をそちらへ寄せる案を出したが, **「推論用標準偏差」は本書のどこでも定義されていない語だった**。……要件定義書§4.4「明確な定義のある用語のみ導入する」に照らして, 直すべきは多数派の側だった。

つまり**「直すべきは推論用標準偏差の側」までは確定しているが, 何に直すかは決まっていない。** ここが唯一, 裁定なしには進めない点。「標本標準偏差」も定義されていないので, 第8章に寄せるのは同じ欠陥への移動にしかならない。

### 判定役の判断

**記号 $u$ をそのまま使い, 名前が要る位置では「不偏分散の平方根」と書く。**

根拠は三つ。

1. **本書がすでに定義しているのはこの二つだけ**である（第4章 `:284`）。新しい名前を立てれば定義ブロックが要り, 第4章の定義の直後にもう一つ名前を置くことになる。$u$ は第4〜9章を通して使われている記号で, 読者はこれを持っている。
2. **大半の箇所は名前を落とすだけで通る。** 例: 第5章 `:166`「平均 $\bar{x} = 170$\,g, 推論用標準偏差 $u = 12$\,gだった」→「平均 $\bar{x} = 170$\,g, $u = 12$\,gだった」。数値を並べる位置では記号で足りている。
3. **名前が要るのは説明の位置だけ**で, そこでは「不偏分散の平方根」が正確に対象を指す。第4章 `:305`「分子の $u$ は, データそのものの散らばりの大きさを推論用に計算した値だ」→「分子の $u$ は, データそのものの散らばりを不偏分散から計算した値だ」。

第6章 `:42`「各グループの推論用分散を人数で割った $u^2/n$」→「各グループの不偏分散を人数で割った $u^2/n$」。**これは定義語への単純な復帰**で, 迷いがない。

第8章 `:234`「各変数の標本標準偏差を求める」→「各変数の $u_x, u_y$ を求める」（直後の式がまさに $u_x, u_y$ を定義している）。

第4章 `:405` は トラック3 と重なる箇所で, 両方を当てると:
```
$u$ は, 一本一本の作品の視聴回数がどれだけ散らばっているかを, 不偏分散から見積もった値である.
```

**仰ぎたいのはこの方針の可否。** 「$u$ をそのまま使う」で通すか, それとも名前を一つ立てて定義するか。名前を立てるなら第4章の定義ブロックに手が入るので, 文体パスではなく説明トラックの仕事になる。
