## 採用5件の確定内容

### ch02-2 四分位数の計算規則 — 採用

中央値には偶数個の場合分けが明示されているのに, 直後の四分位数には非整数位置の規則がない。場合分けを真面目に読んだ読者 — 本書が最も大事にすべき層 — が手を動かした時点で確実に止まる。修正は定義ブロック内の一行（位置が整数にならないときは前後の値を按分する）に限定し, 検算用の小例は挟まない（手法節は6統計量の連続導入区間で, これ以上の密度増は不可）。裏取り済みの事実: 本文の実践値 Q1=57.2 / Q3=263.4 は線形補間方式の値に一致するため, この一行で数値との整合が取れ, 方式選択に悩む必要はない。

### ch02-3 偏差ベクトル — 採用（縮約）

処置案の全削除は採らない。事実確認の結果, 第2章には図が一つもなく, この段落は章内で唯一絵が浮かぶ箇所である。一方, 現状は息継ぎとして機能していない — 「ベクトル」の新語導入・三平方の定理・√n の操作を重ねる章内最難度の6文で, しかも最終文が「二乗でなければならないと示すものではない」と自らの効用を打ち消して終わる（リズム原則§1「結末がしぼむ」）。後続章での再利用もない（横断検索で確認済み）。

第三の道を採る: **「標準偏差は平均からの距離として読める」という結論のイメージだけを残し, ベクトルの語・三平方の定理・自己打ち消しの締めを落とす**（約338字→100字前後）。位置は現在のまま, 単位の話へ渡す前の短い休符として置く。

### ch05-3 割合の正規近似 — 採用（限定）

p が 0 や 1 に近い場合の破綻は区間が 0〜1 をはみ出す形で自己顕在化するため, 誤った結論へ静かに至る経路は細い。ただし本文は「p が 0 や 1 に近いほど SE が小さくなる」と説明しており, 読者を「極端な割合ほど精度がよい」という逆向きの印象に一歩押している。修正はケース2の末尾に**兆候の一文のみ**: 区間が 0〜1 をはみ出したらこの作り方の使いどきの外にいる, という判別可能な合図。条件式や新しい前提項目, 代替手法の名前は足さない（行き先のない名前だけの紹介を新たに作らない）。

### ch05-4 「ばらつき u を下げる」 — 採用

5件で最も明確な採用。この誤用（対象を絞って幅を狭める）は数字の上に破綻の兆候が出ず, きれいな数字のまま通り抜ける。しかも章の山場「精密に間違える」のわずか10行手前で, 「対象を絞る」を n を増やすのと同じ質の正当な手として無防備に推奨しており, 章が最も強調した教訓とその直前の推奨が噛み合っていない。

修正: 現在ひとまとめの「第二の手」を性質の異なる二つに割る — (a) 同じ問いのまま u を下げる工夫（測定条件の安定化）, (b) 推定の対象そのものを変える操作（対象を絞る・層別）。(b) には「狭くなった幅は元の問いに対する精度ではない」を明示し, 直後の「精密に間違える」への伏線として機能させる。層ごとの推定を母集団へ戻す手続きには踏み込まない。節末の「見かけの幅を変えるだけ」の切り分けの対象範囲も併せて見直す。分量は中立〜微増（既存2行の分割で足りる）。

### ch07-5 Satterthwaite区間 — 採用（再構成）

負荷の跳ね上がりは3箇所と特定された: ①モーメント合わせから ν の式への橋がなく天下り（脚注のほうが本文より情報が濃い）, ②未定義の「調和平均」（読者が唯一検算できる箇所を未定義語が塞ぐ）, ③ガンマ関数入り密度式7行（支えるはずの結論は直前で既に述べ終わっており, 「階乗を実数へ滑らかに延ばした関数」の一言に置き換え可能な状態で置かれている）。

処置案は次のとおり修正して採る:

- **「発展資料へ分離」は不可能**（付録の仕組みが本書に存在しないことを main.tex と docs/ 全文検索で確認）。分離ではなく, 落として一行に言い換える。
- **図は新設しない**（第7章は図ゼロ, ch07 スクリプトも不在。密度式の妥当性は図で示せない）。代わりに**少数の比較値**: ν を 68 / 68.936 / 69 としたときの p 値を並べ, 「端数のまま使ってよい」を読者が数値で納得できる形に着地させる。読者が実際に抱く「69 に丸めてよいのでは」という疑問への答えを作る。
- 骨格の維持: 動機と問い立て（A段）・正規分布からの類推（B段）・w_i 書き直しと n1=n2 での一致確認（D段）・結論（E段前半）は残す。
- 落とすもの: 密度式ブロックと読み下し, 調和平均の名指しと脚注。
- 動かすもの: 「ν は近似先の t 分布を指定するパラメータであって個数の勘定ではない」という結論を C 段冒頭へ前倒し。「期待値と分散を合わせる」は何のそれかを名指しする形へ（脚注の内容を本文へ上げる）。
- 「自由度という言葉が二つの意味を持つ」の項（結論の三重化が生じる）は, 書き直し稿を見て統合か独立かを判定役が判断する。

効果は行数ではなく**新規語彙の削減**に出る（「調和平均」「密度関数」「ガンマ関数の式形」の3語が章の最終盤から消える）。

**実施順序の制約**: 比較値の p は片側/両側で変わるため, この再構成は横断2（両側検定への統一）の**後**に行う。数値は判定役が計算して差し替え文に埋め込む（Codex に計算させない）。

## 不採用4件の確定理由（要点）

- **ch02-1**: 読者が日常で実際にやっている受け取り方の代弁であり, 回収先（「後の章で推定という言葉で丁寧に扱う」）も明示済み。成立条件を書くには第4章の語彙が必要で, 概念導入順序に反する。
- **ch04-4 ケトレー**: 重複ではない。第2章は「平均の押しつけ」, 第4章は「正規分布の押しつけ」と対象が違い, その章の道具に即した教訓になっている。削ると胸囲のエピソードが着地を失い, 息継ぎ不足と診断された章の緩和装置だけが痩せる。数十ページ隔てた再登場は重複ではなく想起の機会。
- **ch06-1**: 後段が冒頭と同じ「白黒をつける」の語を拾い直す伏線回収で, 読者の内声（「境界の前後でそんなに違うものか」）を代弁してから答える設計。処置案は未導入語彙の先渡しで, 章の入口という最も離脱しやすい位置の密度を上げる。
- **ch08-4**: ラベルの根拠は慣用分類表ではなく直前の節の散布図（ρ=0.3 と 0.8 の姿）として与えられており, 実践の r=0.3650 / 0.8033 はその図に対応する。章の結論は絶対ラベルでなく相対順序で閉じる。留保の挿入は章で唯一「冒頭の問いにはっきり答えられる」報われる場面を損なう。（記録: 将来手を入れるなら「ラベルを図に結び直す」方向, 分量中立。）
