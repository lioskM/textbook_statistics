# 言語仕上げパス 設計

- 日付: 2026-08-09
- 設計者: Claude Code（判定役）
- 位置づけ: 説明精査パス（全24コミット反映済み, 基準 `5e428ca`）の後段。従来計画の「全章の言語仕上げパス」の実施設計。
- 準拠文書: リズム原則v4 / 翻訳調の族リストv7 / 要件定義書v15 §4.5・§4.6 / 修正方針 §1（優先順位: 内容の正しさ → 読者の疑問への応答 → 面白さ・読み切りやすさ → 数値と図の整合 → 形式要件）

## 1. 目的と範囲

動かすのは**文の表面だけ**である。翻訳調・構文欠陥（族1〜5）, 語り口の乱れ（§4.5アンチパターン）, リズムの崩れ, 新旧本文の継ぎ目の不揃い。意味・構成・数値は変えない。通読中に内容レベルの問題（誤り・未回収の予告など）を見つけた場合は, このパスで直さず別件としてエスカレートする。

置換件数の目標は置かない（効率化は目的にしない）。直すべきものがなければ直さないことも成果である。

## 2. 検査の二層

**層1: 欠陥の検出**（族リストv7）。族1〜5と族未満の採取, 非該当条件集をそのまま適用する。判定の手順則を厳守する:

- 慣用の存在確認で止めず, **当該表面形がそのレジスタで流通しているか**まで確認する（「ここでは置く」の教訓）。迷ったら web 検索。
- **口語それ自体は欠陥ではない**。周囲の文体との釣り合いで個別判断し, 線引きを規則化しない。
- 族への機械的該当だけを理由に, 内容や余韻を壊す書き換えをしない（修正方針 §1 の優先順位に従う）。

**層2: 語り口とリズム**（リズム原則§1「避ける引力」・§2「向かう方向」・§3の字句確認, 要件§4.5アンチパターン, §4.6 推奨パターンP1〜P5）。検問所として使わない。生成の方向は条文ではなく Before/After ペアに学ぶ。

## 3. 対象の優先順位

1. **説明精査パスで入った新規本文の全量**（`1cfdb83..HEAD` の追加行, 約130行 + 図キャプション）。族走査を一度も受けていない。起草者（判定役）自身の文だからこそ同じ基準で検査する。**設計時点で判定役が自覚している候補が既に2件ある**: 「ゴセットの自由度がそのまま顔を出すのだ」（第7章）と「残差そのものが目安をくれる」(第9章) — いずれも §4.5 擬人化・擬態化の候補。判定はバッチ内で行うが, 自分の文にも同種の癖が出るという事実自体がこのパスの必要性の証左である。
2. **第3章冒頭2小節**。族リストv7 の走査実績メモが「言語仕上げパスの優先再訪先」と明記している区画（族5の係り受け崩壊が集中発生した場所）。第7群で書き直したが, 書き直し文がまさに新規本文であり, 再訪判定は必要。
3. **継ぎ目**: 挿入・差し替え箇所の前後1段落。一文ずつは成立していても呼吸が揃っていない可能性が最も高い。
4. **全章通読**（第1章→第10章の順）。読者が経験する順序で読む。リズムの連続性は前から読まないと判定できない。

## 4. 方法と体制

| 工程 | 担当 | 内容 |
|---|---|---|
| 機械走査 | 判定役 | 族リストv7「走査の手がかり」のパターンと実装規定に従い全章を grep。新規本文には §4.5 アンチパターンの照合も加える。候補は判定前の候補にすぎない |
| 通読 | **判定役（委譲しない）** | 章順に通読。主務は「通読の手がかり」4項目の照合ではなく, **リスト外の違和感を自分の判断で挙げること**（第1回パス実測: 機械9件 対 通読23件）。第1章を最初に読み直して語りの基準（P1〜P5の原器）を再校正してから第2章へ進む |
| 反証 | Opus 5 | 判定役の候補一覧に対する**反証役**。(a) 現行文は本当に欠陥か（流通確認・機序判定の再検証）, (b) 提案文自体が新たな翻訳調・語り口の乱れを持ち込んでいないか, (c) 意味と余韻が保存されているか。一次発見には使わない — 言い回しの一次判定は前任判定者の失敗が起きた場所であり, 通読は判定役が手放さない |
| 採否 | Ryosuke | バッチごとの候補一覧（現行文 → 提案文 + 根拠）で判断 |
| 実行 | Codex | 逐語の差し替え指示書。**文体規範を条文で渡さない** — 逐語の現行文・差し替え文と, 根拠としてのペア番号・族番号のみ。逸脱は結果の良し悪しによらず報告 |
| 検収 | 判定役 | grep 照合 + diff と指示書の突き合わせ + ビルド確認 |

## 5. バッチ構成（4バッチ・章順）

1. **バッチ①: 第1〜3章**。第1章の基準再校正から開始。優先再訪先（第3章冒頭）と第7群の新文を含む。
2. **バッチ②: 第4〜5章**。第5群・正確性修正の挿入文とその継ぎ目。
3. **バッチ③: 第6〜7章**。新規本文が最も多い区画（両側化・信頼区間・Satterthwaite再構成・進路宣言）。
4. **バッチ④: 第8〜10章**。第10章は正確性修正5件+再掲圧縮の継ぎ目が集中。

各バッチの流れ: 走査+通読 → 候補一覧作成（現行文→提案文, 根拠は族番号/ペア番号/§4.5項目名のいずれかで特定） → Opus反証 → 修正して確定 → Ryosuke採否 → 指示書 → Codex実行 → 検収。判定文書は `judgments/` に恒久保存, 指示書は使い捨て（確立済みの運用）。

## 8. 留意事項

- **リズム原則 ペア4・5 の After が現行本文と不一致になった**（第7群が第3章の当該箇所を書き直したため）。判断: **現状維持を提案**。ペアは Claude 出力と修正版の対比から生成の方向を学ぶための歴史資料であり, 現行本文との同期は目的ではない。ペア5の差異欄が言う「見えてこない／うまくいかないみたいだ の言い直しが息継ぎ」は新本文には存在しないが, これはペアの教えの失効ではなく適用対象が変わっただけである。リズム原則の変更履歴に注記するかは Ryosuke 判断（注記なしで支障はないと見る）。
- 第1章は第1回パスで検出0件・語り口の基準章。バッチ①での通読は「基準の再校正」が主目的であり, 修正は原則発生しない見込み。
- 修正方針 §1 のとおり, 統計的主張の意味を変えうる修正案が出た場合は, このパスの枠外として個別に判定記録を立てる。
